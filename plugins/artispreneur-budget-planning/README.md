# Artispreneur Budget & Runway

## What it connects to and sends

The only network endpoint is https://www.artispreneur.com/mcp, with 9 read-only tools, server version 1.2.1. Claude sends it only the arguments of a tool call, such as a skill slug, a release date or an EPK audience. The server needs no account, stores nothing from the call, and cannot read or change any Artispreneur account. The skill works without it.
