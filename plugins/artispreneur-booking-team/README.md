# Artispreneur Booking Team

Artispreneur Booking Team desk agent for independent musicians: Venues, tours, and booking pitches from the live directory. Includes the desk as a Claude subagent and as a skill for claude.ai chat. Drafts only; nothing is sent, filed or paid.

Published by Artispreneur Inc. This is one listing from the Artispreneur collection; the `artispreneur` plugin bundles every skill and desk. Legal, tax and money content is general information, not professional advice.

## What it contains

- `agents/booking-team.md`: the desk as a subagent (Claude Code and Cowork; claude.ai chat ignores agents).
- `skills/booking-team-desk/SKILL.md`: the same desk as a skill, so it also works in claude.ai chat.
- `.mcp.json`: one remote MCP server, `artispreneur`, at https://www.artispreneur.com/mcp (Streamable HTTP, no authentication).
- No hooks, scripts, executables, or local servers.

## What it connects to and sends

The only network endpoint is https://www.artispreneur.com/mcp, with 9 read-only tools, server version 1.2.1. Claude sends it only the arguments of a tool call, such as a skill slug, a release date or an EPK audience. The server needs no account, stores nothing from the call, and cannot read or change any Artispreneur account. The skill works without it.

## Install

```bash
claude plugin marketplace add diamitani/artispreneur-claude-plugin
claude plugin install artispreneur-booking-team@artispreneur
```

On claude.ai: Customize > Plugins > Add > Upload plugin, with a zip of this folder.
